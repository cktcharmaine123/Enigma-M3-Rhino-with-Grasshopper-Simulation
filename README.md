# Enigma-M3-Rhino-with-Grasshopper-Simulation
A simulation of the machine via Rhino 8 with Grasshopper. It is a 3-rotor cipher machine used by the German Navy during WW2. This simulation includes 3 rotos, a reflector and a plugboard. It is an attempt to connect the 3D geometry from Rhino to the action operation in grasshopper
